# Fitometría

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23352834.svg)](https://doi.org/10.5281/zenodo.23352834)

Software de visión por computadora para medir área foliar, contar semillas y estimar daño foliar.

**Abrir la app:** https://jmezosolis.github.io/fitometria/

Este repositorio contiene solo la versión publicada de la app. El uso es gratuito.
