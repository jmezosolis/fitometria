## English

**Fitometría** is computer vision software for measuring leaf area, counting seeds and estimating leaf damage.
It runs in the web browser of a phone or a computer and measures with the camera. The interface is available
in Spanish and English.

**Open the app:** https://jmezosolis.github.io/fitometria/

- **Leaf area:** area, perimeter, length, width, shape indices and CIELAB color of each leaf.
- **Seed counting:** number, mean size, variation and thousand-seed weight.
- **Leaf damage:** percentage of yellowish, brown and perforated surface, and number of lesions.

It is calibrated with a printed template (four marks and a grey scale, included as a PDF) that gives the scale,
corrects camera tilt and corrects color.

This repository contains only the published build of the app. It is free to use, under the
[CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/) licence.
